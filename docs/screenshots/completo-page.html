Providers & API keys

Model providers and their API keys belong to the harness, not to Completo. Add or change one under Settings -> Models -> Add model provider -> Custom model API: pick the protocol (OpenAI Chat Completions, OpenAI Responses or Anthropic Messages), the endpoint and the model ids, then paste the key there. The key goes into the harness credential store and is never shown again; that store is what every model call uses, so Completo keeps no copy of anything.

  1. Open Settings -> Models.
  2. Press Add model provider and choose Custom model API for any OpenAI- or Anthropic-compatible endpoint.
  3. Fill the provider id, endpoint, protocol and at least one model id, then paste the API key.
  4. Pick that model in a new conversation and send a one-line prompt to prove the key works.

Keys the MCP servers read

The four optional servers are off. A server is a child process: the harness strips every ambient KEY/PASSWORD/SECRET/TOKEN variable before spawning it, so only the env block in cordis.patch.yml reaches it, and that block reads process.env when the row starts. A value typed on this page could therefore never configure a server, which is why there is no box to type one into. Set the variable in the shell that launches DeepSeek Harness, restart it, then switch the row on.

CONTEXT7_API_KEYcompleto-mcp-context7

Optional. Raises the documentation lookup limits; that server works without it.

In that shell: $env:CONTEXT7_API_KEY=<value>

GITHUB_TOKENcompleto-mcp-github

A personal access token with repository read. That server runs from the Docker image ghcr.io/github/github-mcp-server.

In that shell: $env:GITHUB_TOKEN=<value>

DATABASE_URLcompleto-mcp-postgres

A read-only connection string for a scratch database. Never point it at production.

In that shell: $env:DATABASE_URL=<value>

The Playwright browser row needs no key at all, which is why it is the one that ships on.

A server reads its key once, when it starts. Re-enable the row after changing a value.

Remove it with: dsh plugin --profile <name> remove dsh-completo
